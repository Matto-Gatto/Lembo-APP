# Cartella Caricamento Materiali (Inbox)

Questa cartella è destinata al caricamento diretto dei file e delle cartelle del corso dal tuo computer.

### Come utilizzarla:
Puoi trascinare o incollare qui dentro:
- **Testi d'esame e tracce** (PDF, immagini, file `.txt` o `.py`)
- **File di dati e supporto** usati negli esercizi (es. file `.csv`, file di testo come `I_Malavoglia.txt`, `Partite.csv`, matrici, dizionari)
- **Dispense o script integrativi** (es. `tester.py`, moduli del professore)
- **Intere sottocartelle** (ad esempio una cartella per ogni appello o tema d'esame)

---
*Ogni volta che incolli o estrai nuovo materiale qui dentro, scrivimelo in chat e io provvederò ad analizzarlo, risolverlo, integrarlo nella Wiki e sincronizzare la repository GitHub!*
