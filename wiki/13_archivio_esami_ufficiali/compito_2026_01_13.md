## Ex1(l): Filtro Stringhe Senza Cifre Consecutive
**Traccia:**  
Data una lista $l$ di stringhe, restituisce una lista, **ordinata alfabeticamente**, contenente le stringhe di $l$ che **non contengono due cifre consecutive** (cioè non hanno due caratteri adiacenti appartenenti a `'0123456789'`).  
*Esempio:* `l = ['blink182', 'sole', 'circo', 'alfa0', 'B20']` $\rightarrow$ `['alfa0', 'circo', 'sole']` (`'blink182'` ha `'182'`, `'B20'` ha `'20'`).

### Soluzione Ufficiale:
```python
def Ex1(l):
    cifre = '0123456789'
    ris = []
    for s in l:
        due_cifre = False
        for i in range(len(s) - 1):
            if s[i] in cifre and s[i + 1] in cifre:
                due_cifre = True
                break
        if not due_cifre:
            ris.append(s)
            
    ris.sort()
    return ris
```

## Ex2(file): Mappa Lunghezza $\rightarrow$ Parola Alfabeticamente Maggiore
**Traccia:**  
Dato il nome di un file di testo `file`, restituisce un dizionario che associa alla lunghezza di ogni parola trovata nel file la parola alfabeticamente più grande tra quelle di quella lunghezza. Se il file è vuoto restituisce `{}`.  
*Nota:* Le parole con apostrofo (es. `l'erba`) contano come parola singola; delimitatori sono gli spazi bianchi e `\n` (`s.split()`).

### Soluzione Ufficiale:
```python
def Ex2(file):
    d = {}
    with open(file, "r", encoding="UTF-8") as f:
        for riga in f:
            parole = riga.split()
            for p in parole:
                lunghezza = len(p)
                if lunghezza not in d:
                    d[lunghezza] = p
                else:
                    if p > d[lunghezza]:
                        d[lunghezza] = p
    return d
```

## Ex3(file): Agenti con Più Mesi di Guadagno Massimo (CSV Variabile)
**Traccia [Solo Fondamenti di Programmazione I]:**  
File CSV con vendite mensili. Prima riga: nomi degli agenti (numero arbitrario). Righe successive: guadagni di ciascun agente nel mese corrispondente.  
Restituisce l'**insieme (`set`)** dei nomi degli agenti con performance migliore (coloro che hanno totalizzato il maggior numero di mesi in cui hanno guadagnato il massimo rispetto a tutti gli agenti in quel mese). A parità mensile, più agenti possono condividere il massimo dello stesso mese. Se il file è vuoto restituisce `set()`.

### Esempio:
```csv
Maria,Marco,Alberto,Giorgia
34,30,40,38
41,35,40,40
28,35,40,35
34,29,20,20
34,38,20,38
```
Mese 1: Alberto (40)  
Mese 2: Maria (41)  
Mese 3: Alberto (40)  
Mese 4: Maria (34)  
Mese 5: Marco (38) e Giorgia (38)  
Totale vittorie: Alberto 2, Maria 2, Marco 1, Giorgia 1 $\rightarrow$ Restituisce `{'Alberto', 'Maria'}`.

### Soluzione Ufficiale:
```python
def Ex3(file):
    with open(file, "r", encoding="UTF-8") as f:
        prima_riga = f.readline().strip()
        if len(prima_riga) == 0:
            return set()
            
        nomi = [n.strip() for n in prima_riga.split(",")]
        # Dizionario: nome_agente -> conteggio_mesi_vinti
        vittorie = {nome: 0 for nome in nomi}
        
        for riga in f:
            riga = riga.strip()
            if len(riga) > 0:
                valori = [int(v.strip()) for v in riga.split(",")]
                if len(valori) == len(nomi):
                    max_mese = max(valori)
                    for i in range(len(nomi)):
                        if valori[i] == max_mese:
                            vittorie[nomi[i]] += 1
                            
    if len(vittorie) == 0:
        return set()
        
    max_vittorie_assolute = max(vittorie.values())
    if max_vittorie_assolute == 0:
        return set()
        
    migliori = {nome for nome, v in vittorie.items() if v == max_vittorie_assolute}
    return migliori
```

## Ex4(l): Voto Massimo per Studente da Lista di Tuple
**Traccia [Solo Fondamenti di Informatica]:**  
Data una lista non vuota di coppie `(nome_studente, voto)`, restituisce un dizionario `{nome_studente: voto_massimo}`.  
*Esempio:* `[('Mario', 27), ('Fabio', 28), ('Mario', 30), ('Luca', 18), ('Luca', 21)]` $\rightarrow$ `{'Mario': 30, 'Fabio': 28, 'Luca': 21}`.

### Soluzione Ufficiale:
```python
def Ex4(l):
    d = {}
    for nome, voto in l:
        if nome not in d or voto > d[nome]:
            d[nome] = voto
    return d
```
